# 🖼️ Image Resizing & Conversion Tool

A desktop application for batch image processing, built to practice **asynchronous programming** and **multi-threading** in C#.  
It resizes images, converts formats, and saves them in a new folder with progress tracking.

---

## 🚀 Features
- Select a folder of images and **resize them in bulk**.  
- Maintain **aspect ratio automatically** (height adjusts when width is set).  
- Convert between image formats (e.g., PNG → JPG).  
- Save processed images to a new folder.  
- **Progress tracking** with percentage indicator.  
- **Cancel process** at any time.  
- Built with **async/await** and **multi-threading** for performance.  

---

## 🛠️ Tech Stack
- C#  
- .NET Framework  
- WinForms  
- Async/Await & Multi-threading
